# Contribuer

Projet personnel, ouvert aux retours. Aucune licence n'est accordée pour l'instant (voir la section « Droits » du README) : ouvrez une issue avant tout travail important afin d'en discuter.

1. Forkez le dépôt et créez une branche à partir de `main` : `feat/...`, `fix/...`, `docs/...`.
2. Gardez des changements ciblés, sans fichier généré ni secret.
3. Vérifiez en local avant de proposer une PR :

```bash
npm test
```

4. Messages de commit conventionnels (`feat:`, `fix:`, `docs:`, `refactor:`, `test:`).
5. Ouvrez la PR vers `main` en remplissant le modèle. Ce dépôt fait partie du projet RememberMe avec [Frontend_RememberMe](https://github.com/nagoloumdaniel/Frontend_RememberMe) : mentionnez tout changement qui impacte l'autre dépôt (contrat d'API, CORS, variables d'environnement).

Vulnérabilités : voir [SECURITY.md](SECURITY.md).
